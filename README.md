This is the first version of my portfolio website.

Primarily I used this project to test out features for my final version.

I made this on vscode using basic html and css.

Visuals:
I wanted my website to have a little personality so I gave it a picnic theme. The idea was to make the content box look like a picnic blanket 
and make the side content look like grass. In order to execute this idea I made components such as the contact box a postcard 
and my profile photo a polaroid. Some element I drew by hand.
